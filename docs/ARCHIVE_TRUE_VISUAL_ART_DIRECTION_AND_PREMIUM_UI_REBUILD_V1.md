# MEGA_BATCH_ARCHIVE_TRUE_VISUAL_ART_DIRECTION_AND_PREMIUM_UI_REBUILD_V1

## الهدف
إصلاح الفجوة بين القبول التقني والقبول البصري. الدفعة السابقة نجحت تقنيًا لكنها بقيت قريبة من شكل بطاقات تقليدي. هذه الدفعة تعيد إخراج الواجهة العامة ومساحة العمل بمنطق Art Direction حقيقي.

## التغييرات
- إعادة بناء الصفحة العامة كـ Premium National Archive Gateway.
- Hero سينمائي يجمع الوثيقة والمكان والزمن والوقف.
- طبقات بصرية: ورق مخطوط، خريطة مساحية، ختم مسودة، خط زمني، ومشهد معماري.
- بطاقات كتالوجات أغنى بصريًا وذات هوية لكل حقبة.
- مركز تشغيل داخلي جديد بدل لوحة يومية تقليدية.
- مؤشرات تشغيلية لمسارات metadata، التمثيلات، OCR، الترجمة، المراجعة، والنشر المحجوب.

## الحدود
- لا اتصال خارجي.
- لا OCR فعلي.
- لا ترجمة فعلية.
- لا نشر عام.
- كل الطبقات تبقى مسودات تطويرية إلى حين اعتماد بشري.
